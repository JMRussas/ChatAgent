# Documentation retrieval agent — development findings

The standalone LangChain/Ollama slice completed four development smoke cases on
`gemma4:26b` with prompt `docs-tgr/4`. All structural checks passed. Manual review
supports the three positive answers against their retrieved passages. The unknown
case declined to invent a cost, but its claim about what the documents contain
was broader than the bounded retrieval established. This is not four proven
factual-quality passes or a held-out benchmark.

## Earlier attempts and resulting changes

These artifacts intentionally retain failures. Models and implementation changed
between attempts, so the results cannot rank models or compare prompt formats.

- [Qwen3.5 v1](qwen35-2026-09-26/metadata.json): context-limit and repeated-tool
  failures. Bounds were insufficiently visible in schemas, and the initial input
  budget was too small. Exposed argument constraints and adjusted the input budget.
- [Qwen3 Coder v2](qwen3coder-v2-2026-09-26/metadata.json): guessed citation ranges,
  excessive quote length and exhausted retrieval. Replaced model-authored citation
  locations with host-issued evidence IDs resolving to actual read ranges.
- [Gemma4 v3](gemma4-v3-2026-09-26/metadata.json): fenced JSON, wrong citation IDs,
  and an unsupported answer without retrieval. Added a bounded retrieval reminder
  and a final synthesis using an Ollama JSON schema whose citation enum contains
  only evidence IDs actually issued during the run.

The final synthesis is an additional inference call within the existing budget.
It is a provider output constraint, separate from section formatting in prompts.

## What the evidence establishes

Fifteen deterministic offline tests pass, covering corpus isolation, snapshots,
budgets, tool validation, message handling, invalid citations and terminal paths.
The nine prompt-contract and seven prompt-encoding tests also still pass.
No production TypeScript behavior or application dependency changed.

Citation validation establishes reference identity, not semantic support. A model
can still overstate a passage. Lexical search also misses paraphrases and can match
generic words. These are reasons to preserve telemetry for later evaluation,
not to treat successful completion as an automatic learning signal.

The next learning exercise is to express the same state and transitions explicitly
in LangGraph, preserving these evidence and budget contracts. Broader evaluation,
semantic review and responsive-runtime integration remain separate work.
