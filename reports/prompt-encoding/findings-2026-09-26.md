# Prompt encoding: live pilot findings — 2026-09-26

## Outcome

Completed **240 scored local Ollama calls**: five distinct model digests × twelve cases × four encodings, plus five excluded warmups. No transport failures or length-truncated outputs. Ollama version 0.34.4 ran on Windows localhost; requests originated from WSL through PowerShell. No model downloads or cloud inference occurred.

Full prose had the highest aggregate content score in this pilot. Compact representations used fewer input tokens on average, but did not consistently preserve answer selection. These results do not establish a universal format ranking.

## Observations

- Qwen3:8b and Qwen3-coder favored prose over each compact representation on this set.
- Qwen3.5 tied prose and concise text in content accuracy; its raw prose score was reduced by entity prefixes.
- Gemma4 scored 11/12 with XML and 10/12 with each other representation: a one-case difference, not a statistically established advantage. It fenced every answer, failing strict JSON compliance despite mostly correct selections.
- Qwen2.5-coder fenced 47 of 48 outputs; its raw exact score therefore greatly understates content selection accuracy.
- Concise input reduced average reported input tokens by about 9.9%, JSON by 8.3%, and XML by 1.5%. XML averaged slightly more tokens than prose for Gemma4.
- Some errors involved explicit negation, dependencies, objective revision and scope. This matters for the proposed context layer: small instructions can still be lost or misapplied.

### gemma4:26b: scope

- json: expected `["A", "C"]`, observed `"```json\n{\"answer\":[\"A\",\"C\"]}\n```"`.
- xml: expected `["A", "C"]`, observed `"```json\n{\n \"answer\": [\n  \"A\",\n  \"C\"\n ]\n}\n```"`.
- prose: expected `["A", "C"]`, observed `"```json\n{\n  \"answer\": [\n    \"A\"\n  ]\n}\n```"`.
- concise: expected `["A", "C"]`, observed `"```json\n{\n \"answer\": [\n  \"A\",\n  \"C\"\n ]\n}\n```"`.

## Interpretation and next experiment

Keep the typed context-package and configurable-renderer design, but do not choose XML/JSON globally based on an assumed efficiency benefit. Preserve prose as the control.

This experiment uses shallow structured fields containing compact rule/record strings. It does **not** yet evaluate fully nested entity records or explicit graph edges for every relationship. Full prose versus compact forms also changes lexical wording and uses logical notation. The experiment measures these particular representations as a package, not structure alone.

A follow-up should preregister answer normalization, vary input and output formats independently, include full-word structured conditions and nested records, test longer/distractor-rich held-out cases, and repeat with multiple seeds and controlled thinking settings. That would separate wording, explicit relationships, serialization, output compliance and sampling effects. The same model/case pairs should remain the basis of comparisons.

Do not select a model or renderer permanently from twelve cases with one repetition. Fixed model order, uncontrolled cache/hardware state and provider defaults limit latency comparisons. No automatic context evaluation, learning policy or production renderer was added.
