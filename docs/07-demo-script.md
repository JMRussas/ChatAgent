# Demo Script (8-10 minutes)

## Storyline

"This assistant responds immediately, then improves itself asynchronously when deeper analysis is needed."

## Demo steps

1. Direct prompt
- Ask a simple conceptual question
- Show immediate complete response

2. Deep prompt
- Ask for current data with citations
- Show provisional response in under 1s
- Show refined follow-up with source links

3. Clarification prompt
- Ask ambiguous short query
- Show clarification question behavior

4. Provider swap
- Flip provider config from Azure profile to Bedrock profile
- Re-run one deep prompt and compare metrics

5. Metrics slide
- Show latency, quality score, citation rate, and route distribution

## Talking points for employers

1. Architectural tradeoffs
2. Route decision policy
3. Evaluation-driven iteration
4. Cross-cloud portability and vendor risk reduction
